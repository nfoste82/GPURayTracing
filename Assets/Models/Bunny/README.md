# Stanford Bunny Benchmark Asset

`stanford-bunny-69451.obj` is the 69,451-triangle Stanford bunny mesh used by
`Benchmark_BunnyCopper`. It was downloaded from the public Common 3D Test
Models collection:

https://github.com/alecjacobson/common-3d-test-models/blob/master/data/stanford-bunny.obj

The original Stanford bunny is attributed to the Stanford Computer Graphics
Laboratory. This local copy preserves the triangle count used by the reference
copper-bunny render so renderer benchmarks exercise equivalent mesh geometry.
